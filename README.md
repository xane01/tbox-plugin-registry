# TBOX Plugin Registry

Official test registry for TBOX TERMUX.

## Trust and security

Plugins execute with the same permissions as the TBOX user. Only install plugins from repositories you trust. The registry is a test catalog and is not an endorsement of third-party code.

## Registry index

The package index is published at `https://raw.githubusercontent.com/xane01/tbox-plugin-registry/main/repo-index.json`.
